# Signature Sound Vienna: FAIR Data Corpus
Collection of Linked Data for the project Signature Sound Vienna, characterizing its collection of audio recordings relating to the Vienna Philharmonic Orchestra's New Year's Concerts. This repository is split into three sections:

- The /data subdirectory contains Linked Data descriptions of our recordings collection, with entities adhering to types of the [Music Ontology](http://purl.org/ontology/mo/).
- The /annot subdirectory contains musicological objects (Web Annotations, under /oa/) and music objects (under /mao/) adhering to the [Music Annotation Ontology](https://doi.org/10.1145/3543882.3543891).
- The /vocab RDF files contain the project's very limited custom vocabulary set.

Linked Data files are provided in a variety of serialisations, which may be requested using content negotiation through proxy URIs provided under the <https://w3id.org/ssv> namespace. 

Motivation for this data corpus is provided in the following publication: 

David M. Weigl, Chanda VanderHart, Matthäus Pescoller, Delilah Rammler, Markus Grassl, Fritz Trümpi, and Werner Goebl. 2022. The Vienna Philharmonic Orchestra’s New Year’s Concerts: Building a FAIR Data Corpus for Musicology. In Proceedings of the 9th International Conference on Digital Libraries for Musicology (DLfM '22). Association for Computing Machinery, New York, NY, USA, 36–40. <https://doi.org/10.1145/3543882.3543892>

A more extensive description of the corpus is currently under review.
